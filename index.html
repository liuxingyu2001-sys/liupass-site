Liupass 战令 / 通行证插件

适用于 Paper / Leaf 1.21 以上版本服务器的战令系统，支持多赛季、三档位购买、自定义任务与奖励。

查看使用文档

功能特点

  • 多通行证，每个赛季独立配置
  • 普通、高级、豪华三档位独立购买
  • 支持 PlayerPoints 点券与 Vault 金币
  • 任务类型：击杀、挖掘、合成、钓鱼、附魔、酿造、进食、在线时长、登录、自定义
  • 每日、每周、赛季任务周期
  • 奖励类型：指令、物品、CraftEngine 模型、金币、点券
  • MySQL 或 SQLite 数据存储
  • Redis 跨服同步（可选）
  • PlaceholderAPI 变量与 PassAPI 开发接口
